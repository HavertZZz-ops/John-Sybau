# John-Sybau

Prototipo de jogo 2D em Python + Pygame. feito em pygame.

## Como rodar

```bash
pip install -r requirements.txt
python run.py
```

## Como testar sem abrir janela

```bash
python test_smoke.py
```

## Controles

- setas ou W/S: navegar no menu
- enter ou espaco: confirmar
- esc: sair
